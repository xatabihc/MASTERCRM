# MasterCRM 2.0.0 — Release Candidate 1

**Статус: предварительный выпуск (RC), не стабильная 2.0 Stable.**

MasterCRM Offline — полностью локальная Android CRM для мастеров: клиенты, заказы, статусы и сроки, частичные платежи, возвраты, расходы, долги, фотографии «до/после», PDF заказ-наряд, защищённые резервные копии.

## Изменения относительно 1.9

- Просмотр фотографий больше не загружает в память все JPEG из заказа: карточка читает только метаданные, затем последовательно подгружает миниатюры в фоновом потоке. Большое фото читается только по нажатию «Посмотреть».
- Фото выбираются строго в контексте заказа, поэтому чужой идентификатор не возвращает данные другого заказа.
- Дополнительные Android-тесты подтверждают работу с настоящими JPEG в трёх размерах: 120 реальных изображений проходят экспорт, проверку и восстановление защищённого `.mcrm5`, декодируются после восстановления.
- Сохранены тесты 1.9: 1400 синтетических заказов, 800 JPEG-подобных фото, сбои чтения/записи архива, проверки меню с увеличенным шрифтом, работа Android 14/15 и запрет разрушительных тестов на физических телефонах.
- Выпускной процесс автоматически проверяет **три зелёных GitHub Actions на одном коммите** — Android CI, подпись APK, сохранность данных при обновлении с предыдущих подписанных Preview. Только после этого публикует APK и SHA-256 в GitHub Releases как предварительную версию. Приватные ключи подписи в процессе публикации не используются.

## Установка и сохранность данных

- Имя приложения: MasterCRM Offline.
- Пакет: `com.mastercrm.offline.preview`. Это **не** исходная MasterCRM 0.9.4. Она не заменяется и не мигрируется.
- Для обновления уже установленной подписанной Offline Preview используется `adb install -r MasterCRM-2.0.0-rc1.apk`. **Не используйте `adb uninstall`**.
- Перед обновлением рекомендуется вручную создать **защищённую** копию `.mcrm5` в приложении, сохранить её вне телефона и проверить целостность через меню «Проверить копию». Сохраните пароль в надёжном месте.
- Отсутствуют регистрация, интернет-разрешение, облачная синхронизация и автоматическое фоновое резервное копирование. Файлы, которые пользователь выбирает для экспорта через системный диалог, могут оказаться в облачном хранилище стороннего провайдера.

## Известные ограничения и условия Stable

- Нет подтверждённых семидневных испытаний у 10–20 независимых мастеров на разных физических устройствах — [реестр результатов](BETA_RESULTS_2_0.md).
- Восстановление на отдельном физическом устройстве и проверка тысяч настоящих фотографий ещё не выполнены; синтетические тесты не заменяют реальное использование.
- Нужен полный физический аудит доступности, в том числе TalkBack, крупный шрифт и особенности разных Android-прошивок.
- `.mcrm5` защищён паролем, но сам локальный файл SQLite не зашифрован дополнительно силами приложения; его безопасность зависит в том числе от блокировки экрана и шифрования Android.
- Старый JSON-экспорт не шифруется, находится в дополнительном меню и **не рекомендован** для хранения личных данных.

Работы до стабильной 2.0 отслеживаются в [задаче №26](https://github.com/xatabihc/MASTERCRM/issues/26). **Отмечать этот Release Candidate как Stable нельзя до подтверждения испытаний.**

## Проверка подлинности

Скачивайте APK только из GitHub Releases данного репозитория. Рядом с APK доступен `SHA256SUMS.txt`, сформированный из того же подписанного файла. Сверьте `sha256sum MasterCRM-2.0.0-rc1.apk` с опубликованным значением.
