# MasterCRM Offline 1.3 — поиск

Новая версия расширяет поиск заказов: по номеру, названию услуги, **описанию**, имени и телефону клиента.

Поиск ищет буквальное вхождение текста (без специальных шаблонов). Символы `%`, `_` и `!` обрабатываются как обычные символы, поэтому ввод `5%` находит записи именно с `5%`. Все входные значения передаются в SQLite через параметры; вручную SQL не строится из пользовательского текста.

Одинаковая логика используется в клиентском поиске, фильтре постоянных клиентов, основном поиске заказов и истории повторных услуг. Данные и финансовые расчёты не меняются.

## Совместимость и проверка
- Приложение `com.mastercrm.offline.preview`, SQLite schema 2, архивы `.mcrm5` и сертификат подписи остаются прежними.
- Проверить строки с `%`, `_` и `!`, а также поиск слов только из описания заказа.
- В Android CI запускается `CrmStoreTest.clientAndOrderSearchTreatsWildcardsAsLiteralAndFindsDescriptions`.
- Устанавливать только подписанный APK поверх предыдущей Preview через `adb install -r`; не удалять приложение и его данные.
- Оригинальная MasterCRM 0.9.4 — отдельный пакет, её данные не затрагиваются.
