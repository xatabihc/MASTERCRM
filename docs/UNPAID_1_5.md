# MasterCRM Offline 1.5 — список заказов с задолженностью

В разделе **Заказы** появилась кнопка «Показать заказы с задолженностью». Она включает просмотр всех неархивных заказов с остатком к оплате больше нуля. Список отсортирован по убыванию долга: самые большие неоплаченные суммы сверху.

Фильтр работает вместе с обычным поиском (номер, услуга, описание, клиент, телефон), выбором статуса и постраничным просмотром по 100 записей. Спецсимволы `%`, `_`, `!` трактуются буквально. Нажатие на повторное переключение показывает все заказы.

Сумма долга рассчитывается из сохранённой цены заказа и реальных платежей, включая возвраты. Полностью оплаченные заказы и архив исключены. Данные в SQLite при чтении списка не изменяются.

## Защита пользовательских данных

- Не меняются `applicationId=com.mastercrm.offline.preview`, SQLite schema 2, формат защищённого архива `.mcrm5`, логика подписи.
- Изменения не требуют миграции данных и дополнительных разрешений Android.
- Android SQLite-тесты проверяют сортировку, полную оплату, возврат, фильтрацию по статусу и 105 записей на двух страницах.
- Устанавливать только подписанный выпуск Preview поверх прежней подписанной версии через `adb install -r`. Не выполнять `adb uninstall`.
- Оригинальная MasterCRM 0.9.4 — отдельно установленное приложение и не является целью обновления.
