# Конфиденциальность MasterCRM Offline — информация для пользователей

**Область действия:** приложение MasterCRM Offline Preview (`com.mastercrm.offline.preview`). Не относится к оригинальной MasterCRM 0.9.4.

## Какие данные обрабатываются
Пользователь сам вводит локально имена и телефоны клиентов, описания и стоимость заказов, платежи, расходы и фотографии. Эти данные хранятся в локальной базе SQLite внутри приложения.

## Передача данных
В текущем AndroidManifest нет разрешения INTERNET, нет обязательной регистрации или встроенной аналитики/рекламных SDK. **Встроенной синхронизации с сервером нет.**

Данные могут покидать приложение **только по явному действию пользователя**:
- сохранение резервной копии или PDF в выбранный через системный файловый интерфейс документ/папку, в том числе у стороннего облачного провайдера;
- использование системного меню «Поделиться» для сводки заказа;
- выбор камеры или изображения через внешние системные приложения.

Сведения об устройстве или действиях пользователей не отправляются разработчику автоматически. Сам Android и выбранные приложения хранения/обмена имеют собственные правила обработки данных.

## Резервные копии и защита
Рекомендуемый формат — защищённая паролем копия `.mcrm5` с AES-256-GCM и PBKDF2. Пароль не записывается в настройки или GitHub. Если пароль потерян, разработчик не сможет открыть копию. Обычный экспорт JSON **не зашифрован** и может содержать контакты и фотографии.

**Важно:** саму локальную базу приложения нельзя считать дополнительно зашифрованной внутри MasterCRM. Безопасность данных на устройстве также зависит от блокировки экрана, шифрования Android и состояния телефона.

Приложение не создаёт фоновые автоматические копии. Пользователь выбирает, куда сохранить защищённый архив, и должен отдельно обеспечить его сохранность.

## Сообщения об ошибках
Публичные GitHub Issues доступны всем. Не публикуйте туда имена/телефоны клиентов, реальные фотографии, резервные копии, пароли, коды доступа, ключи подписи или необработанные скриншоты с личными данными. Используйте вымышленные примеры.

## Удаление
Локальные данные остаются в приватном хранилище Android до удаления данных или самого приложения системой/пользователем. Файлы, отдельно экспортированные пользователем через системный интерфейс, удаляются в том месте, где они были сохранены; удаление приложения не удаляет их автоматически.

Документ описывает фактическое поведение имеющейся версии, но не является юридическим заключением.
