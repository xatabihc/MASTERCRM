# Восстановление основной Android-версии

## Принцип
Новый проект — безопасная офлайн-демонстрация с package `com.mastercrm.offline.preview`.
Он **не является обновлением** установленного MasterCRM 0.9.4 и не имеет к нему доступа.

Пока исходники и signing key 0.9.4 не восстановлены:
- Нельзя менять applicationId на имя оригинала и обещать обновление поверх него.
- Нельзя удалять установленную версию и сбрасывать её данные.
- Нельзя считать JSON-формат превью совместимым со старой базой.
- Нельзя выкладывать реальную базу клиентов или ключ подписи в публичный GitHub.

## План
1. Найти проект 0.9.4 в сохранённых папках/архивах Ubuntu. Есть безопасный скрипт `tools/audit-local-mastercrm.sh`.
2. Установить точный package ID и certificate fingerprint оригинального APK, найти исходники и подпись без передачи секрета в чат/репозиторий.
3. Создать локальную резервную копию данных и протестировать обновление только на тестовом устройстве/копии.
4. Перенести проверенные улучшения из `app/` в оригинальную кодовую базу, сохранив миграции.
