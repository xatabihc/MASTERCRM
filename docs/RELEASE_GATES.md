# Критерии выпуска MasterCRM 2.0 Stable

Это план, а не обещание и не утверждение о проведённых испытаниях.

## Блокирующие требования
1. Все изменения защищены тестами и объединены в main с успешными проверками CI.
2. Подписанный APK проверен по package ID, увеличению versionCode, сертификату SHA-256, отсутствию неожиданных разрешений и установлен поверх предыдущей подписанной Preview на тестовом эмуляторе.
3. Доказана сохранность клиента, заказа, платежей, расходов, фото и срока при обновлении и восстановлении `.mcrm5`.
4. Ошибки повреждённого файла, неверного пароля, нехватки места и отмены действия не должны оставлять базу частично импортированной.
5. Проведена проверка с большими синтетическими базами и несколькими Android-версиями.
6. Проверен реальный пользовательский сценарий у добровольных бета-тестировщиков (см. BETA_TEST_GUIDE.md), устранены блокирующие проблемы.
7. Есть понятные инструкции о локальном хранении данных, приватности и неэквивалентности оригинальной 0.9.4.
8. Публикация финальной версии проводится через GitHub Releases с контрольной суммой APK и описанием ограничений.

## Допустимо в бета-версии
Предварительные UX-улучшения, новые необязательные функции, экспериментальные сценарии — только при условии, что они не вредят целостности финансов и резервных копий.

## Не делать
- Не маркировать версию Stable только потому, что зелёный CI.
- Не публиковать в репозиторий реальные фотографии клиентов, базы или файлы подписания.
- Не заменять оригинальную MasterCRM 0.9.4 пакетом Offline Preview.
- Не переносить данные реальных пользователей в эмулятор без согласия и обезличивания.
