# MasterCRM Offline Preview (Android)

![Android CI](https://github.com/xatabihc/MASTERCRM/actions/workflows/android-ci.yml/badge.svg?branch=develop%2Fandroid-offline-rebuild)

**В разработке.** Независимый офлайн Android-проект. Не замена и не обновление ранее установленной MasterCRM 0.9.4.

## Что реализовано в исходниках

- Русский интерфейс: обзор, заказы, клиенты, финансы, настройки.
- SQLite: клиенты, заказы, статусы, сроки, поиск по номеру/клиенту/телефону, платежи, возвраты, расходы.
- Деньги хранятся целым количеством копеек, без ошибок округления `float`.
- Дашборд: поступления, расходы, кассовая прибыль, долги, активные и просроченные заказы.
- Создание/редактирование клиентов и заказов, история оплат, частичные оплаты.
- Экспорт/импорт резервной копии JSON через системный выбор файла.
- Импорт полностью транзакционный: ошибка сохраняет прежние данные. Перед импортом есть предупреждение о замене.
- PDF заказ-наряда через Android `PdfDocument` (не фискальный чек).
- Тёмная и светлая темы, собственная векторная иконка.
- **Никаких разрешений на интернет**, платных API, учётных записей или внешних серверов.
- GitHub Actions: unit test, Android Lint, сборка `app-debug.apk`, публикация в артефакты workflow.

Важные незавершённые пункты: фото «до/после», полноценный выбор клиента из длинной базы, архив/дублирование без ручной формы, испытание на реальном устройстве и проверка миграции из 0.9.4. Этот репозиторий пока не претендует на релиз 1.0.

## Как получить APK через GitHub

1. Откройте [Actions](https://github.com/xatabihc/MASTERCRM/actions/workflows/android-ci.yml).
2. Выберите **зелёный** успешный workflow на ветке `develop/android-offline-rebuild`.
3. В блоке Artifacts скачайте `mastercrm-offline-preview-debug`.
4. Распакуйте ZIP, установите `app-debug.apk` на Android (или `adb install -r app-debug.apk`).

Отладочный APK имеет отдельный package ID `com.mastercrm.offline.preview`; это сделано намеренно, чтобы не повредить оригинальную 0.9.4. Не удаляйте оригинальное приложение ради установки превью.

## Сборка в Android Studio

- JDK 17, Android SDK 35, Gradle 8.9 / Android Gradle Plugin 8.7.3.
- Откройте корневую директорию проекта как Android-проект.
- Запустите `gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug` с установленным Gradle 8.9.
- APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Пока Gradle Wrapper jar отсутствует. GitHub Actions самостоятельно устанавливает точную версию Gradle.

## Безопасность

- Никаких реальных данных, БД, ключей подписи, `.env`, токенов или клиентских фото в публичном репозитории.
- `android:allowBackup="false"`: приложение не выгружает содержимое БД через автоматическое облачное резервное копирование Android.
- Резервная копия JSON содержит персональные сведения клиентов **в открытом виде** — храните её только в защищённом месте.
- Восстановление в текущей Preview-схеме не совместимо автоматически с БД MasterCRM 0.9.4.
- Не используйте Preview для реальных клиентских данных до успешных тестов на устройстве и проверки экспорта/импорта.

## История и восстановление

По предыдущему отчёту MasterCRM 0.9.4 Professional была проверена, но Android-исходников в этом репозитории не было. Независимая проверка 0.9.4 не проводилась. Подробнее: [docs/RECOVERY.md](docs/RECOVERY.md).

Автоматический поиск исходников на Ubuntu: `tools/audit-local-mastercrm.sh`. Скрипт ничего не изменяет и ничего не загружает.
