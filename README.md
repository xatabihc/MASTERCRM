# MasterCRM — Android CRM для мастеров и самозанятых

> **Состояние репозитория:** восстановление актуальных Android-исходников. Этот репозиторий **ещё не содержит исходный код MasterCRM 0.9.4** и из него пока нельзя собрать APK.

## Цель

Довести приложение до стабильной **MasterCRM 1.0** без обязательной подписки, сервера, платного API и постоянного интернета. Базовые функции — локально на Android.

## История и исходная точка

- **0.9.4 Professional** — по предыдущему отчёту разработчика собрана и проверена: клиенты, заказы, поиск, платежи, задолженности, расходы, фото «до/после», финансовый обзор и графики, PDF, резервное копирование/восстановление, темы.
- **0.9.5** — разработка прервалась после потери рабочей среды; итоговая сборка и подпись не подтверждены.
- **0.7** — существует отдельная историческая *Django/web* версия, но она **не является** исходниками Android 0.9.4. Не смешивать архитектуры и базы без отдельной миграции.

Пункты выше — сведения из истории разработки, не результат проверки текущей сборки. После восстановления нужно подтвердить их автоматическими тестами.

## План восстановления

1. Найти на Ubuntu **последние настоящие Android-исходники 0.9.4/0.9.5**, включая локальные Git-ветки и архивы.
2. Найти информацию о **подписи APK** (наличие файлов ключа, не раскрывая их содержимое) и убедиться, что идентификатор пакета совместим с установленной версией.
3. Создать резервную копию исходников и сохранить тестовую пользовательскую базу только в локальном, защищённом месте.
4. Импортировать исходники в ветку разработки, **не загружая** персональные данные, ключи подписи, токены или `.env`.
5. Собрать APK, прогнать тесты и протестировать **обновление поверх 0.9.4 без потери данных** на тестовой копии.
6. Исправить UI, навигацию, скролл, функции заказов и финансов. Только затем принять решение о локальном/необязательном ИИ.

## Ограничения безопасности

**Никогда не коммитить:** `*.keystore`, `*.jks`, `*.pem`, `*.key`, `*.env`, `local.properties`, файлы БД, реальные резервные копии пользователей, клиентские фото, API-токены, реальные номера телефонов и заказы.

Нельзя удалять установленное приложение ради переустановки при конфликте подписей — это может уничтожить его данные.

## Поиск локальной копии

На Ubuntu можно выполнить безопасную проверку (скрипт не изменяет файлы):

```bash
curl -fsSL https://raw.githubusercontent.com/xatabihc/MASTERCRM/main/tools/audit-local-mastercrm.sh -o /tmp/audit-local-mastercrm.sh
bash /tmp/audit-local-mastercrm.sh
```

Скрипт показывает потенциальные местоположения Android-проекта и только наличие файлов подписи — **не считывает и не раскрывает ключи, пароли и базы данных**.

## Правило работы

Работа ведётся через отдельные ветки и проверяемые изменения. Никаких разрушительных миграций, удаления данных и публикации подписанных APK без подтверждения совместимости.
